# Listen and Repeat

Practice for the *Listen and Repeat* task of the TOEFL iBT (2026 format).

- 12 scenes, 60 sets, 540 sentences.
- Each set has 7 sentences that get longer: 6–9 words, then 10–13, then 14–19.
- Sentences 6 and 7 also come in an extra-long version of 21–25 words, for memory training.
- Exam timing: each sentence plays once, then 2 seconds, a tone, and 8, 10 or 12 seconds to repeat it (15 for the extra-long sentences).
- United States, United Kingdom and Australia accents (it uses the voices on the device), with adjustable speed up to 1.5×.
- Every picture shows objects that the sentences mention.
- It records each answer so that you can compare it with the original sentence.
- It can be installed and used offline.

Page: https://corretegil-ar.github.io/listen-repeat/

This is not official ETS material.
