# Listen and Repeat

Práctica de la tarea *Listen and Repeat* del TOEFL iBT (formato 2026).

- 12 escenarios, 60 sets, 420 frases.
- Cada set tiene 7 frases que se alargan: 5–8 palabras, 9–12 y 12–18.
- Tiempos de examen: la frase suena una vez, 2 segundos, tono y 8, 10 o 12 segundos para repetir.
- Acentos de Estados Unidos, Reino Unido y Australia (usa las voces del equipo), con velocidad regulable.
- Graba cada respuesta para compararla con la frase original.
- Se puede instalar y usar sin conexión.

Página: https://corretegil-ar.github.io/listen-repeat/

No es material oficial de ETS.
